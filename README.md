# Радовалка

PWA для двоих: письмо дня, конверты «Открой, когда…», общий экран «Вместе».

Код — только оболочка. Письма, даты, фото и всё личное хранятся на сервере
(Cloudflare Worker + D1) и открываются лишь по личной ссылке с ключом.

- `worker/worker.js` — сервер: два ключа — две половины, без ключа 401.
- Локально: `node dev/local-api.mjs` (API на 8787) + `py dev/serve.py` (8102).
