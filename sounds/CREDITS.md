# Записи инструментов

Файлы в этой папке — отдельные ноты из звукового банка **FluidR3 GM** (автор — Frank Wen),
в виде MP3 из проекта [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts).

Лицензия: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

| Папка | Инструмент банка |
|---|---|
| kalimba | kalimba |
| harp | orchestral_harp |
| flute | flute |
| violin | violin |
| cello | cello |
| bass | acoustic_bass |
| bells | glockenspiel |

Файлы не изменены; в приложении у каждой ноты срезается тишина в начале и меняется высота.
